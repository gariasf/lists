# Publishing to the Figma Community

Publishing is GUI-only — Figma desktop app, no CLI and no API. Everything below
is ready to paste into the publish modal.

**Prerequisites:** Figma desktop app, and 2FA enabled on your Figma account
(waived if you sign in with Google/SAML SSO).

## Assets

Generated by `node packages/figma-plugin/make-listing-assets.mjs`, in `listing/`:

- `icon-128.png` — 128×128, the site's own mark
- `cover-1920x1080.png` — 1920×1080 cover

## Listing copy

**Name**

```
Lists — realistic mock data
```

**Tagline**

```
Fill selected text layers with names, cities, and UI copy that look real.
```

**Description**

```
Stop typing "Text Text Text" into your mockups.

Lists fills your selected text layers with curated, realistic data: Brazilian
names, German postal codes, order statuses, chat messages, validation errors,
dashboard metrics — 431 lists in all.

How it works
1. Select one or more text layers (or a frame containing them)
2. Search the catalog and pick a list
3. Hit Fill — each layer gets a different item
4. Shuffle re-rolls with a fresh sample

Layers fill in reading order — top to bottom, then left to right — so a filled
table or list reads the way it looks, not the order you happened to select in.

The data is curated by hand, not generated: locale-coherent profiles where the
name, city, postal code and phone actually agree, microcopy that sounds like a
real product, and deliberately awkward strings for testing truncation.

Free, no account, no key. Browse everything at lists.gariasf.com.
```

## Click path

1. Figma desktop → open any design file
2. Figma logo (top-left) → Plugins → Manage plugins
3. Under **Development**, find *Lists — realistic mock data* → Publish
4. **If it says "Invalid ID":** click **Generate ID** in the modal, paste the
   value into `manifest.json` as `"id"`, save, reopen the modal. The current id
   in the manifest is a local-development placeholder — Figma issues the real
   one here, and only a human clicking that button can create it.
5. Page 1 — name, tagline, description, category (copy above)
6. Page 2 — upload `listing/icon-128.png` and `listing/cover-1920x1080.png`,
   add tags
7. Page 3 — the security disclosure form is optional and adds up to two weeks
   to review; skip it unless you want the badge
8. Submit

## Review

No official SLA. Figma staff historically quote 5–10 business days, but through
2026 the backlog has been running longer — plan for a few weeks. You keep
publishing updates without re-review once it's live.
